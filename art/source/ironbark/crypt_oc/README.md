# Lost Keep crypt asset drafts

Eight generated PNG sheets normalized to the requested canvas sizes and native pixel grids using nearest-neighbor sampling. Alpha is binary; OC5 is opaque. OC1 and OC5 were created as new anchors because previously approved versions were not attached.

## Important limitations

These are generated asset drafts, not certified production-ready tiles. Exact seamless repetition, corner mating, the 96+96px edge shadow treatment, five tones per material, individual prop dimensions, and all requested silhouette details are not fully satisfied or validated. Some generated extra architectural dressing remains. Sampling to the requested native resolution reduces the detail of the generated source artwork. No claim of hand-placed pixel authorship is made.

OC1 band guides and OC7 strip bounds were assembled on the native grid. Island, balcony and ledge pieces were placed at the requested nominal widths; irregular transparent margins can make visible occupied widths smaller.

Use nearest texture sampling when importing. Collision should be authored separately from decorative silhouettes.
