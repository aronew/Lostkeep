# Lost Keep

2D side-view Metroidvania in **Godot 4.7.2**, aiming for top-tier presentation.

Before any design, room, or asset work, read:
- `design/pillars.md`: non-negotiables (exploration first, floors not platforms, black-box collision, parallax camera, vignette)
- `design/ability-atlas.md`: every ability and what it can do
- `design/lock-and-key.md`: every lock, key source and shortcut
- `design/world-and-regions.md`: lore, Kindreds, regions, critical path

Art prompt books live in `docs/art-production/` (reference images in `lostkeep-attach/`).
